# Schemas

The JSON Schemas define a minimal interoperable normal form:

- `state.schema.json` - typed state with time, sheet, lineage and branch.
- `event.schema.json` - verified relation/support/compatibility event.
- `expected_event.schema.json` - obligation that can support a later negative event.
- `absence_event.schema.json` - absence emitted only with complete coverage and no matching event.
- `compatibility_predicate.schema.json` - versioned physical/policy/consent coupling decision.
- `lineage.schema.json` - derivation, split, merge, version and branch provenance.
- `application_record.schema.json` - application-atlas row.

These are prototype schemas, not an adopted industry standard.
