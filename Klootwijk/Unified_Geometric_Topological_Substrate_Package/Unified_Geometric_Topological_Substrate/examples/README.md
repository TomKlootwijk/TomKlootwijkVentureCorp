# Examples

- `equation_world_zero.py` loads the JSON world, evaluates state, solves and applies the next event, checks a double-vacuum coupling case, and writes an event log.
- `topology_demo.py` exercises Mobius/Klein quotient maps and the four-chamber hourglass router.
- `graphics_preview.py` produces five loop-to-R morph frames as grayscale PGM and 1-bit PBM files.
- `fractal_preview.py` generates a Pascal-parity Sierpinski test pattern.
- `bce_demo.py` runs a measured threshold stream through the Bounded Compatibility Event controller.

Run with `PYTHONPATH=src` from the package root.
