# Data files

- `source_manifest.*` - source IDs, roles, page counts, paths, and hashes.
- `document_role_map.*` - authority and contribution of each source.
- `operator_lexicon.*` - source motif to technical operator mappings.
- `normalization_rules.*` - retain/translate/demote/reject rules.
- `claims_matrix.*` - claim, evidence status, disposition, and source pages.
- `query_matrix.*` - query inputs, operations, outputs, and failure modes.
- `terminology_occurrences.csv` - term occurrence inventory.
- `page_term_index.csv` - page-level term index.
- `operator_edges.csv` - ontology relationships.
- `corpus_ontology.jsonld` - JSON-LD graph.
- `corpus_ontology.graphml` - GraphML graph.
