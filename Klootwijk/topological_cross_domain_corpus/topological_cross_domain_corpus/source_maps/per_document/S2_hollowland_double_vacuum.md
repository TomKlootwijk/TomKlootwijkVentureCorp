# S2 - hollowland-double-vacuum

## Role

Generative source for much of the corpus's topology and computer-science vocabulary. It is also the source of several inflated performance claims, so its operators are retained while totalizing conclusions are demoted.

## Technical contributions by page

- **pp. 12-13:** log-polar 1-bit LUT, Klein-bottle boundary conditions, analytic sweeping cones, and the initial mistaken return to raymarching.
- **pp. 14-17:** explicit user correction away from rasterization/raymarching; analytic solids, SDF as algebraic boundary, phase alignment, parity flip, and direct event roots.
- **pp. 18-19:** lighthouse sweep around `SDF=0`, event horizon, phase-layer routing, and multiscale chirp language.
- **pp. 20-23:** eigenvectors/eigenvalues as invariant axes and scale/rank variables; `lambda=0` as an off/null-space event motif.
- **pp. 23-25:** inverted quad hourglass, four chambers, central pinch, sheet routing, and parity transition.
- **pp. 26-30:** kinematic calculus, procedural grammar, analytic CCD, and ontological UUID/world-state fusion proposals.
- **pp. 30-33:** sieve bypass and compact memory estimates, both of which remain hypotheses rather than established results.
- **pp. 34-36:** world/AI unification and cache-native intelligence claims; these are outside the bounded core.

## Normalization used here

- "double vacuum" -> incompatible co-located sectors;
- "Klein bottle" -> orientation/gluing map;
- "hourglass" -> routing partition and event locus;
- "one bit" -> parity/route flag;
- "O(1), zero memory" -> rejected as universal claims.
