# S7 - KC Vector Graphical Art System

## Role

Downstream computer-graphics and prepress adapter. It is important precisely because it shows how the non-image substrate could still emit conventional outputs without becoming identical to them.

## Technical contributions by page

- **pp. 1-3:** Cartesian-to-log-polar address transform, implicit SDF/CSG operators, boundary gradient, phase-amplitude accumulation, and 1-bit output.
- **pp. 4-6:** display bridge via temporal 1-bit pulse-density modulation and anisotropic spatial dithering.
- **pp. 7-8:** chromatic offsets as log-radius shifts and stochastic subpixel blending.
- **pp. 8-10:** print/prepress bridge via CMYK mapping, log-polar blue noise, SDF edge locking, and dot-gain compensation.

## Terminology correction

"Feynman vectors" are not formally derived in the source. This package preserves the intended phase/amplitude behavior but calls the operator a phase-amplitude edge accumulator.
